# Учебное приложение. Слот-машина 

Простое приложение сделаное на Flutter. Крутишь барабан, получай 3 в ряд и выигрывай!

## Как играть
---
- Нажмите **Крутить** чтобы запустить барабаны
- Три в ряд - победа (+3 монеты)
- Тря в ряд 7 - ДЖЕКПОТ (+10 монет)
- Разные символы - проигрыш (-1 монета)
- Начинате с начала кнопкой **Начать заново**

## Запуск проекта
---
